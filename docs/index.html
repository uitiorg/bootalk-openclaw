캘린더 & 연차

일정과 휴가를 말로 관리하세요

Google Calendar와 Gmail CLI를 명시적으로 실행해 일정·연차를 처리합니다. 상주 Slack 봇이 자동으로 실행하지는 않습니다.

Slack 관리

채널과 캔버스를 손쉽게

Slack connector 또는 명시적 Slack API 작업으로 캔버스와 멤버를 관리합니다. OpenClaw Socket Mode는 사용하지 않습니다.
